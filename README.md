# 📊 Social Media Engagement Analytics Using Python

## 📌 Project Overview

This project focuses on analyzing social media engagement data using Python. The analysis was performed on **5,000 social media posts** to identify patterns in content performance, audience behavior, engagement, sentiment, device usage, and posting time.

The project was completed using **Google Colab** with Python-based data analysis and visualization libraries.

---

## 🎯 Objectives

The main objectives of this project are:

* Import and understand social media engagement data.
* Clean and preprocess the dataset.
* Explore numerical and categorical variables.
* Analyze relationships between engagement metrics.
* Create meaningful engagement features.
* Perform statistical analysis.
* Visualize social media trends and patterns.
* Identify the best-performing content types and categories.
* Analyze audience behavior based on age, device, country, and sentiment.
* Generate data-driven insights from the dataset.

## 📈 Key Findings

Based on the analysis:

* **Best Performing Post Type:** Video
* **Best Performing Category:** Music
* **Best Performing Country:** France
* **Best Performing Sentiment:** Negative
* **Best Performing Age Group:** Below 18
* **Highest Average Watch Time:** Mobile
* **Best Posting Time:** 12:00 AM (Midnight)
* **Highest Engagement Rate:** Negative Sentiment

These findings are based on the analyzed dataset and help identify patterns in social media audience engagement.

---

## 📝 Conclusion

The analysis shows that content type, category, audience characteristics, sentiment, device usage, and posting time can influence social media engagement.

Video posts and music-related content showed strong engagement performance. Users below 18 recorded higher engagement, while mobile users had the highest average watch time. The analysis also showed that negative sentiment posts generated higher engagement in this dataset. Posts published around midnight recorded the highest average impressions.

Overall, this project demonstrates how Python-based data analysis and visualization can be used to understand social media behavior and generate data-driven insights.
